# Activity 9: Containerized REST API for Student Records

## Problem statement

<hr>
Build a simple REST API that supports adding, viewing, and updating student records. Package the application into a Docker container and demonstrate that it can be started, stopped, and recreated without manually configuring the host environment.<br><hr>

Expected outcomes:<br>
● Implement a basic REST API.<br>
● Write a Dockerfile and configure required ports.<br>
● Demonstrate API functionality and container lifecycle commands.<br>
